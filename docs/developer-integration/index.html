如何維護與重新產生

原稿集中在 generate.py；source/ 為產生的 HTML 與樣式。修改規格後執行下列命令，產生 PDF 與 ZIP；不要手改 PDF。

python docs/developer-integration/generate.py
# 僅重新產生 HTML
python docs/developer-integration/generate.py --html-only

使用環境既有的 Playwright、Chrome／Chromium；PDF 檢查使用 PyMuPDF。無需連線校務資料庫、開啟網站或讀取本機 appsettings.json。

本文件為目前開發版介面規格；正式網址、系統代碼、密鑰／憑證、授權欄位與測試帳號請向 SSO 管理者取得。example.edu 為示意位址，不可直接呼叫。
