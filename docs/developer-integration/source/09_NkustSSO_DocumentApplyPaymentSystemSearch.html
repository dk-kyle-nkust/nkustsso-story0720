NkustSSO_DocumentApplyPaymentSystemSearch

呼叫端點：https://sso.example.edu/KuasSSOWebService.asmx
WSDL：同網址加 ?wsdl。所有輸入為 XML 字串欄位，必須保留拼字與大小寫。

先登記來源 IP、此方法及允許欄位。接收端先檢查 HTTP／Fault，再判斷業務結果。

輸入參數

名稱型別意義
SearchUsr_idstring原串接系統的呼叫帳號
SearchUsr_pwdstring原串接系統的呼叫密碼
IDNOstring申請者身分證號
Birthdaystring生日字串，直接比對校務生日欄位（最多 7 字元），不自動轉換日期格式
identitystringSTUD：有當期學籍；Employee：教職員；GRADSTUD：查無當期學籍的學生資料，沿用原校務查詢條件
from_Clientipstring原介面傳入的使用者 IP；不能取代伺服器端的來源授權

判定規則

identity 僅接受 STUD、Employee、GRADSTUD（區分大小寫）。Birthday 依來源生日字串比對，1～7 字元，不自動轉換日期。GRADSTUD 是略過當期學籍的舊查詢分支，不保證每列都已畢業。

回傳欄位

欄位／位置提供條件說明
message固定200 成功；500 無符合資料；501 呼叫帳密錯誤
std_id授權學號／員工編號，可能回傳多列
std_name授權姓名
std_email授權電子郵件
個資未授權時保留位置／欄位但值為空；失敗 DataSet 可只有 message。未取得資料不得自行補值。

NkustSSO_DocumentApplyPaymentSystemSearch

SOAP 1.1 請求範例

POST /KuasSSOWebService.asmx HTTP/1.1
Content-Type: text/xml; charset=utf-8
SOAPAction: "http://tempuri.org/NkustSSO_DocumentApplyPaymentSystemSearch"

<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/">
  <soap:Body>
    <NkustSSO_DocumentApplyPaymentSystemSearch xmlns="http://tempuri.org/">
      <SearchUsr_id>CALLER_ACCOUNT</SearchUsr_id>
      <SearchUsr_pwd>CALLER_PASSWORD</SearchUsr_pwd>
      <IDNO>TEST_ID_NUMBER</IDNO>
      <Birthday>SOURCE_BIRTHDAY</Birthday>
      <identity>STUD</identity>
      <from_Clientip>192.0.2.10</from_Clientip>
    </NkustSSO_DocumentApplyPaymentSystemSearch>
  </soap:Body>
</soap:Envelope>

以上均為占位符；Birthday、票據及帳密須代入核准測試資料，不能原樣送出。SOAP 1.2 改用其 Envelope namespace 與 Content-Type action，方法與參數不變。

回應判讀示意

DataSet / Table1（邏輯結果示意）
成功：message="200", std_id, std_name, std_email
可有多列；教職員仍使用 std_ 前綴
查無：message="500"；呼叫帳密錯誤：message="501"

聯調檢查

  • 未授權 IP／方法、錯誤呼叫帳密及來源中斷都不可視為成功。
  • 用 WSDL 產生代理解析陣列型別或 DataSet；不假設 HTTP 200 就表示驗證通過。
  • 驗證未勾欄位為空、密碼欄位不傳送；資料不可送到一般日誌。
HTTP 403 為呼叫資格拒絕；503 為服務未啟用；500／SOAP Fault 須另行處理。服務限制：16 KiB、同來源 IP 每分鐘 60 次。此方法不建立中央 Cookie。
