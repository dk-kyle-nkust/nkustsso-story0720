公用帳號資料查詢

Get_Traffic_Pub

呼叫端點：https://sso.example.edu/KuasSSOWebService.asmx
WSDL：同網址加 ?wsdl。所有輸入為 XML 字串欄位，必須保留拼字與大小寫。

先登記來源 IP、此方法及允許欄位。接收端先檢查 HTTP／Fault，再判斷業務結果。

輸入參數

名稱型別意義
usr_idstring呼叫系統帳號（不是被查詢人的帳號）
usr_pwdstring呼叫系統密碼（不是被查詢人的密碼）
searchIDstring被查詢人的學號／員編／公用帳號，或原始識別號；不是 MD5。保留參數大小寫。

判定規則

先驗呼叫系統帳密，再依查詢值取得唯一對應。查無回 message=500；多筆衝突或來源不可用可能回 Fault，不任取第一筆。 公用帳號限定帳號包含 office，pubusr_idno 為原識別資料，不是摘要。

回傳欄位

欄位／位置提供條件說明
message固定200 成功；500 查無資料；501 呼叫帳密錯誤
pubusr_id授權公用帳號
pubusr_name授權帳號名稱
pubusr_idno授權原始識別資料；不是 MD5
pub_name_abr授權名稱簡稱
types授權公用帳號 P
pwd禁止固定空字串
usr_email授權電子郵件
個資未授權時保留位置／欄位但值為空；失敗 DataSet 可只有 message。未取得資料不得自行補值。

Get_Traffic_Pub

SOAP 1.1 請求範例

POST /KuasSSOWebService.asmx HTTP/1.1
Content-Type: text/xml; charset=utf-8
SOAPAction: "http://tempuri.org/Get_Traffic_Pub"

<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/">
  <soap:Body>
    <Get_Traffic_Pub xmlns="http://tempuri.org/">
      <usr_id>CALLER_ACCOUNT</usr_id>
      <usr_pwd>CALLER_PASSWORD</usr_pwd>
      <searchID>TEST_LOOKUP_VALUE</searchID>
    </Get_Traffic_Pub>
  </soap:Body>
</soap:Envelope>

以上均為占位符；Birthday、票據及帳密須代入核准測試資料，不能原樣送出。SOAP 1.2 改用其 Envelope namespace 與 Content-Type action，方法與參數不變。

回應判讀示意

DataSet / Table1（邏輯結果示意，實際為 XSD＋DiffGram）
成功：message="200"，以及下表中被授權的資料值
查無：只有 message="500"
呼叫帳密錯誤：只有 message="501"

聯調檢查

  • 未授權 IP／方法、錯誤呼叫帳密及來源中斷都不可視為成功。
  • 用 WSDL 產生代理解析陣列型別或 DataSet；不假設 HTTP 200 就表示驗證通過。
  • 驗證未勾欄位為空、密碼欄位不傳送；資料不可送到一般日誌。
HTTP 403 為呼叫資格拒絕；503 為服務未啟用；500／SOAP Fault 須另行處理。服務限制：16 KiB、同來源 IP 每分鐘 60 次。此方法不建立中央 Cookie。
